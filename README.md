Fitness/Workout Tracker

A personal mobible-first Progressive Web App (PWA) built with Python, Flask, SQLite, HTML, and CSS to log gym sessions, calculate 1 rep max, and to track workouts. 

Features
- Multi-Movement logging: Log an entire session (date, focus, exercies, weight, sets, and reps) in one submission>
- 1 Rep Max Calculation: Using the Epley formula to give you an estimated 1 rep max.

Tech Stack 
- Backend: Python, Flask, SQLite
-Frontend: HTML5, Jinja2, CSS3, Vanilla JavaScript
